# 🏋️‍♂️ Constructor de Rutinas

Este repo es una aplicación web minimalista y moderna diseñada para ayudarte a planificar tus entrenamientos diarios de forma rápida y visual. Selecciona tus grupos musculares, elige el equipamiento disponible y genera una lista de ejercicios optimizada para tu sesión.

## 🚀 Características

* **Constructor Inteligente:** Filtra los ejercicios según los músculos que deseas trabajar y el equipo con el que cuentas.
* **Persistencia Local:** Tu rutina y preferencias se guardan automáticamente en el `localStorage`, permitiéndote recargar la página sin perder tu progreso.
* **Sistema de Intercambio (Swap):** ¿No te gusta un ejercicio? Cámbialo por una alternativa similar con un solo clic (de forma manual o aleatoria).
* **Guías Detalladas:** Visualiza animaciones y pasos detallados de ejecución para cada movimiento.
* **Diseño Responsivo y Atractivo:** Interfaz moderna pensada para usarse cómodamente tanto en dispositivos móviles en el gimnasio como en computadoras.

## 🛠️ Tecnologías Utilizadas

* **HTML5 / CSS3:** Estructura limpia y diseño responsivo sin frameworks pesados.
* **JavaScript (ES Modules):** Lógica del cliente modularizada.
* **Node.js (Scripts internos):** Procesamiento y optimización previa del dataset de ejercicios.

## 📦 Créditos y Recursos

* Las imágenes, videos y datos de los ejercicios provienen del excelente repositorio [exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset) creado por Hasan Yıldırım.
